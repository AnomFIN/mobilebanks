CAT (Cryptocurrency Automated Trading) is a simulated trading bot feature that demonstrates automated arbitrage trading between exchanges. In reality, no trades are executed. The feature shows mock activity to illustrate how such a system might work.
All data in CryptoApp is stored locally in your browser using localStorage. No data is transmitted to any server. Since this is a demonstration app with no real value, there are no security risks associated with its use. You can reset all data at any time from the Settings screen.
